## Requirements

- An **Apple Silicon Mac** on **macOS 14** or later. There is no Intel build
  in the alpha and no plan for Linux or Windows.
- Nothing else. [Language servers](/docs/features/language-servers/) are
  optional and found if they are installed.

## Install the app

<Tabs syncKey="install">
<TabItem label="Download" icon="download">

<Steps>

1. Download `crc.dmg`, the newest release's disk image.

   <LinkButton href="https://github.com/caioricciuti/crc/releases/latest/download/crc.dmg" icon="download">Download crc.dmg</LinkButton>
   <LinkButton href="https://github.com/caioricciuti/crc/releases/latest" variant="minimal" icon="external">Release notes</LinkButton>

2. Open it and drag **crc** to **Applications**.

   The app is signed with a Developer ID and notarized, so it opens without a
   Gatekeeper warning.

3. Optionally, check the download against `SHA256SUMS` from the same release:

   ```sh
   shasum -a 256 ~/Downloads/crc.dmg
   ```

   The hash printed should match the line for that file in `SHA256SUMS`.

</Steps>

</TabItem>
<TabItem label="Build from source" icon="seti:rust">

You need Rust 1.98 or newer. The repository pins the exact toolchain in
`rust-toolchain.toml`, so `rustup` fetches it for you.

<Steps>

1. Clone the repository:

   ```sh
   git clone https://github.com/caioricciuti/crc
   cd crc
   ```

2. Build the bundle and install it:

   ```sh
   scripts/bundle.sh --install
   ```

   That puts `crc.app` in `/Applications`, signed with a Developer ID when
   one is available in your keychain, otherwise ad-hoc signed. Local
   installs are not notarized by this command.

3. For a fully offline, auditable build, vendor the crates first:

   ```sh
   scripts/vendor.sh
   ```

</Steps>

</TabItem>
</Tabs>

## Open files and folders

From Finder, drop a file or folder on the Dock icon. From a terminal:

```sh
open -a crc path/to/file    # open a file
open -a crc .               # open the current folder as a project
```

Inside crc, <kbd>⌘</kbd><kbd>O</kbd> opens a file and
<kbd>⌘</kbd><kbd>⇧</kbd><kbd>O</kbd> opens a folder. Recent folders are on the
[home screen](/docs/getting-started/tour/#the-home-screen).

## Updates

Once a day crc asks GitHub for the list of releases and says in the status
line when a newer one exists. The daily check downloads nothing.
**Help › Check for Updates** downloads the newer release when you ask,
then checks its SHA256SUMS, Developer ID signature, bundle identifier,
notarization and version before offering **Restart to Update**.

Restart follows a normal quit: unsaved files ask first, and Cancel keeps
crc running. An app in a location you cannot write to cannot be replaced;
the status line explains the failure. Set `update_check = false` in
[settings](/docs/getting-started/settings/) to turn the daily check off.

If you replaced the app manually or installed a local build while crc was
open, **Help › Restart crc**, the status-line Restart button or Home's
restart action loads the bundle now on disk. Existing terminal helpers
survive this normal restart.

## Uninstall

Drag `crc.app` from Applications to the Trash. crc also keeps a few files of
its own; [Where crc keeps things](/docs/reference/storage/) lists them if you
want to remove those too.
