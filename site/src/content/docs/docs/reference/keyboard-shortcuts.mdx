## Files

| Keys | Action |
|---|---|
| <kbd>⌘</kbd><kbd>N</kbd> | New file, as a name field in the sidebar |
| <kbd>⌘</kbd><kbd>O</kbd> | Open a file |
| <kbd>⌘</kbd><kbd>⇧</kbd><kbd>O</kbd> | Open a folder |
| <kbd>⌘</kbd><kbd>P</kbd> | Open Quickly: fuzzy file open |
| <kbd>⌘</kbd><kbd>S</kbd> | Save |
| <kbd>⌘</kbd><kbd>⇧</kbd><kbd>S</kbd> | Save as |
| <kbd>⌘</kbd><kbd>W</kbd> | Close the tab |
| <kbd>⌘</kbd><kbd>,</kbd> | Open the settings file |
| <kbd>⌘</kbd><kbd>Q</kbd> | Quit |

## Tabs and panes

| Keys | Action |
|---|---|
| <kbd>⌘</kbd><kbd>1</kbd>…<kbd>9</kbd> | Switch to a tab |
| <kbd>⌘</kbd><kbd>[</kbd> / <kbd>⌘</kbd><kbd>]</kbd> | Previous, next tab |
| <kbd>⌘</kbd><kbd>{"\\"}</kbd> | Split the editor to the right |
| <kbd>⌘</kbd><kbd>⌥</kbd><kbd>[</kbd> / <kbd>⌘</kbd><kbd>⌥</kbd><kbd>]</kbd> | Focus the previous, next pane |
| <kbd>⌘</kbd><kbd>⌥</kbd><kbd>W</kbd> | Close the pane |

With the mouse: drag a tab to reorder it, right-click it to manage tabs,
scroll over the tab strip to reveal overflowed tabs, and double-click the
empty strip for a new file.
