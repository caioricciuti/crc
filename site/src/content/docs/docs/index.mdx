## What crc is not

crc is an alpha for Apple Silicon Macs on macOS 14 or later. It is used daily
by its author and is going to a small group of testers first. It has no
extensions, no Intel, Linux or Windows builds, and a fixed set of languages.
The full list is in [Known limits](/docs/reference/limitations/); why it is
built this way is in [Why crc exists](/vision/).
