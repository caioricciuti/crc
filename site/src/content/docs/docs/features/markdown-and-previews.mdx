## Markdown

Markdown renders **in place as you edit**, while the source stays editable.

<div class="crc-keys">
  <div><span>Toggle the Markdown preview</span><span><kbd>⌘</kbd><kbd>E</kbd></span></div>
  <div><span>Word wrap on or off</span><span><kbd>⌥</kbd><kbd>Z</kbd></span></div>
</div>

Markdown and text files wrap long lines by default. The `word_wrap`
[setting](/docs/getting-started/settings/) changes that for every file.

## Everything else

Images, PDFs, audio, video and office documents open as **Quick Look**
previews, the same previews Finder shows.
