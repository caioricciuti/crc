## Markdown

Markdown opens as text, **styled where it is written**: headings in bold,
bold and italic in their own faces, inline code on a tint, links and list
markers set apart, and the characters that make the syntax drawn faint.
Fenced code blocks sit on a band, coloured by their language. Because it
is text, selection, find, multiple cursors and undo work as in any file.

A rendered preview is planned as an extension.

<div class="crc-keys">

</div>

Markdown and text files wrap long lines by default. The `word_wrap`
[setting](/docs/getting-started/settings/) changes that for every file.

## Everything else

Images, PDFs, audio, video and office documents open as **Quick Look**
previews, the same previews Finder shows.
